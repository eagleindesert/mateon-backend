# Mateon Backend API 변경 명세서 (v9-2)

> Base URL: `/`<br/>
> 인증 방식: JWT Bearer Token (`Authorization: Bearer <accessToken>`)<br/>
> Last Updated: 2026-08-31

🔑 **인증**: 인증이 필요한 엔드포인트는 로그인(`POST /api/auth/login`)으로 받은 accessToken 을 우측 상단 Authorize 에 넣으면 그대로 호출해 볼 수 있습니다.<br/>
📌 **안내**: v9부터는 상세 엔드포인트 명세(Request/Response 스키마, 파라미터, 헤더, 상태 코드 등)를 **Swagger UI**가 정본(Single Source of Truth)으로 제공합니다. 본 문서는 프론트엔드(FE) 연동에 필요한 **v9 대비 기능/정책 변경 사항 및 신규 기능 동작 방식**을 텍스트로 정리한 문서입니다.

## 📋 v9 → v9-2 핵심 변경 사항 요약

- **🗺️ 공모전 유사도 지도 API 신설**:
  - `GET /api/events/{eventId}/similarity-map` — 기준 활동과 다른 활동들의 코사인 유사도·방사형 그래프 좌표를 반환한다.
  - 비로그인 허용(활동 검색과 같다). 쿼리 `topN` 기본 500, 최소 1, 최대 500.
  - 응답 id 는 우리 `events.id` (`Long`). 임베딩 벡터는 내려주지 않는다.
  - `radius`·`x`/`y` 는 이번 후보군 안의 **상대 순위**다. 서로 다른 요청의 점 간 거리를 비교하면 안 된다. 색과 UI 는 `similarity` 또는 `rankPercentile` 로 결정한다.
- **🔧 활동 등록 후 임베딩 비동기 계산**:
  - `POST /api/events` 의 201 응답 계약(`EventResponseDTO`)은 그대로다. 프론트가 벡터를 기다리지 않는다.
  - 커밋 뒤 FastAPI `POST /internal/contests/embedding:refresh` 로 1,536차원 벡터를 받아 `event_embeddings` 에 저장한다.
  - 등록 직후 유사도 지도를 치면 아직 벡터가 없을 수 있다 → 400 `EVENT_EMBEDDING_NOT_READY`. 잠시 후 재시도하면 된다.
- **🛠️ PostgreSQL `event_embeddings` 테이블 도입 (V33 마이그레이션)**:
  - `vector(1536)` + 갱신 상태(`SUCCESS`/`FAILED`) + 경합 방어(`source_updated_at`, `version`).
  - `events.embedding_vector`(text) 는 예전부터 비어 있었고 계속 쓰지 않는다. 목록/검색이 Event 행을 통째로 읽기 때문에 벡터를 같은 테이블에 두면 검색마다 따라온다.
- **🆕 에러 코드 `EVENT_EMBEDDING_NOT_READY` (400) 추가**:
  - 기준 활동 행은 있지만 임베딩이 아직이거나 실패한 상태. `TEAM_EMBEDDING_NOT_READY` 와 같은 성격이다.

## 1. 🗺️ 공모전 유사도 지도 (`GET /api/events/{eventId}/similarity-map`)

- **인증 요구사항**: 👤 (선택) — 비로그인도 그대로 쓸 수 있다. 토큰을 보내도 응답이 달라지지 않는다.
- **설명**: 기준 활동을 그래프 중심에 두고, 임베딩이 있는 다른 활동들을 유사도 순으로 배치한다. 계산은 FastAPI 가 하고, 후보 선정과 벡터 저장은 백엔드가 한다.

**Path**

| 필드    | 타입 | 필수 | 설명                            |
| ------- | ---- | ---- | ------------------------------- |
| eventId | Long | ✅   | 그래프 중심이 되는 기준 활동 ID |

**Query**

| 필드 | 타입 | 필수 | 기본 | 설명                                                            |
| ---- | ---- | ---- | ---- | --------------------------------------------------------------- |
| topN | int  | ❌   | 500  | 반환할 최대 후보 수. 1 미만은 1 로, 500 초과는 500 으로 자른다. |

**Response 200 OK (`data`: `ContestSimilarityMapResponseDTO`)**

| 필드                                    | 타입             | 설명                                                                                            |
| --------------------------------------- | ---------------- | ----------------------------------------------------------------------------------------------- |
| query                                   | object           | 기준 공모전의 표시용 정보. 임베딩은 없다.                                                       |
| query.id                                | Long             | `events.id`                                                                                     |
| query.title                             | String           | 제목                                                                                            |
| query.organizer                         | String 또는 null | 주최                                                                                            |
| query.category                          | String 또는 null | `CONTEST` / `EXTERNAL` / `SCHOOL` / `ETC`                                                       |
| query.field                             | String 또는 null | 분야 코드 (`EDUCATION` 등)                                                                      |
| query.fieldLabel                        | String 또는 null | 분야의 한글 표기. `field` 가 null 이면 null                                                     |
| query.detailUrl                         | String 또는 null | 상세 URL                                                                                        |
| points                                  | array            | 유사도 높은 순. 최대 `topN` 개. 후보가 없으면 `[]`                                              |
| points[].id                             | Long             | 후보 활동 ID                                                                                    |
| points[].similarity                     | number           | 코사인 유사도. 이론적 범위 `-1.0`~`1.0`                                                         |
| points[].rankPercentile                 | number           | 반환된 후보군 안 순위 백분위. `0.0` 이 가장 유사, `1.0` 이 가장 덜 유사. 후보 1개면 `0.0`       |
| points[].radius                         | number           | 순위 백분위로 계산한 기준 반지름. 가장 유사하면 `minRadius`, 가장 덜 유사하면 `maxRadius`       |
| points[].x, points[].y                  | number           | 그래프에 바로 쓸 좌표. 원점 거리는 `radius` 를 중심으로 최대 `radialJitter` 만큼 흔들릴 수 있다 |
| maxRadius                               | number           | 기준 반지름 최댓값. 현재 `12.0`                                                                 |
| minRadius                               | number           | 기준 반지름 최솟값. 현재 `2.6`                                                                  |
| radialJitter                            | number           | 점 겹침을 줄이는 최대 흔들림. 현재 `0.5`                                                        |
| referenceRings                          | array            | 상위 10%, 30%, 60%, 90% 지점. 후보가 없으면 `[]`                                                |
| referenceRings[].percentile             | number           | `0.1` / `0.3` / `0.6` / `0.9`                                                                   |
| referenceRings[].similarityAtPercentile | number           | 그 백분위 지점의 유사도                                                                         |
| referenceRings[].radius                 | number           | 그 백분위 지점의 기준 반지름                                                                    |
| candidatePoolTotal                      | int              | AI 가 받은 후보 수 (`topN` 절단 후). DB 전체 공모전 수가 아니다                                 |

**그래프 해석**

`radius` 와 `x`/`y` 는 절대 유사도가 아니라 이번 후보군 안의 상대 순위다. 서로 다른 요청의 점 간 거리를 직접 비교하면 안 된다.

**예외 응답**

- **400 Bad Request** `EVENT_EMBEDDING_NOT_READY`: 기준 활동의 임베딩이 아직 없거나 실패 상태다. 등록은 커밋 후 비동기로 벡터를 채우므로, 방금 올린 활동을 바로 물으면 이 코드가 난다. 잠시 후 다시 호출하면 된다.
- **404 Not Found** `EVENT_NOT_FOUND`: 그 활동 행이 없다.
- **502 Bad Gateway** `AI_SERVER_ERROR`: AI 서버 응답 처리 실패.
- **503 Service Unavailable** `AI_SERVER_UNAVAILABLE`: AI 서버에 연결할 수 없다.

후보가 0건이면 200 이고 `points` 는 빈 배열이다 (오류가 아니다).

## 2. 🔧 활동 등록 시 임베딩 비동기 갱신 (`POST /api/events`)

- **응답 계약은 v9 과 같다.** 201 `EventResponseDTO`. 프론트가 새 필드를 읽을 필요는 없다.
- 저장이 커밋된 뒤 백엔드가 FastAPI 에 제목·설명을 보내 1,536차원 벡터를 받고 `event_embeddings` 에 저장한다.
- AI 장애가 등록 자체를 막지 않는다. 실패한 활동은 백필 스케줄러가 다시 집어 채운다.
- 유사도 지도의 기준 벡터가 이 값이다.

---

## 3. 🛠️ `event_embeddings` (V33)

프론트가 직접 조회하는 테이블은 아니다. 유사도 지도가 비어 있거나 `EVENT_EMBEDDING_NOT_READY` 가 오래가면, 등록 직후이거나 임베딩 갱신이 실패한 상태다.
